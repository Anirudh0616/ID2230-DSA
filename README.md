# Holy Segfault Manifesto


This repo is not “just C code.”  
It’s a spiritual gymnasium for your neurons. Every `printf` is a prayer, every `malloc` a leap of faith.  

## How to run 
```bash
gcc something.c -o something
./something
```

- if it compiles: the code gods have showered us with love.
- if it runs: the code gods want us to join them.
- if it seg faults: Home Sweet Home...

Now go forth, `free()` your soul, and remember:

If it compiles, it’s probably wrong.
If it runs, it’s definitely dangerous.
